# App Perpustakaan

Aplikasi manajemen perpustakaan berbasis web yang dibangun menggunakan framework _Laravel 12_.

## Tujuan

Mempermudah pencatatan katalog buku, manajemen peminjaman, serta pengelolaan anggota perpustakaan secara efisien dan terstruktur.

## Cara Menjalankan Project Secara Lokal

1. Clone repository:

```bash
  git clone -b dev [https://github.com/](https://github.com/)ACILBACKBURNER/app-perpustakaan.git
  cd app-perpustakaan
```
